Local Run Instructions
1. Start FastAPI backend: uvicorn src.uav_risk.api.main:app --reload --port 8000
2. Open this HTML file in a browser (or serve with: python -m http.server 3000)
3. Set API Base URL above to: http://localhost:8000
4. Set Mode to Real and click Apply & Test Connection
5. Create a Drone Profile or select one from Drone Profiles page
6. Go to Risk Analysis, fill in mission/scenario fields, click RUN ASSESSMENT
For demo/local testing without backend: keep Mode = Demo (default)
